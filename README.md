# Simple Interest Calculator

## Project Description

The Simple Interest Calculator is a simple Bash-based application that calculates the simple interest on a principal amount using the annual rate of interest and the time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

Where:
- **Principal:** The initial amount of money.
- **Rate:** The annual rate of interest in percentage.
- **Time:** The duration in years.

## Features

- Accepts the principal amount from the user.
- Accepts the annual rate of interest.
- Accepts the time period in years.
- Calculates simple interest using the standard formula.
- Displays the calculated result.

## Example

**Input:**
- Principal: 1000
- Rate: 5%
- Time: 2 years

**Output:**
- Simple Interest: 100.00

## Requirements

- Bash shell
- A terminal that supports Bash

## How to Run

Clone the repository:

```bash
git clone https://github.com/anushka326/github-final-project.git
```

```bash
cd github-final-project
```

Run the calculator:

```bash
bash simple-interest.sh
```
